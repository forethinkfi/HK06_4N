# 기획 메모

## 타깃
스마트폰·키오스크가 어려운 어르신

## 문제
키오스크/앱 앞에서 막혀도 물어볼 사람이 없음

## 해결
손주 모습의 펫봇이 항상 화면에 떠 있다가, 부르면 쉬운 말로 단계별 안내

## 시간표 (14h)
| 시간 | 목표 |
| --- | --- |
| 0-1h | 역할 분담, 스택 확정 |
| 1-6h | 펫봇 생성 / 플로팅 UI / 챗봇 API 각자 구현 |
| 6-10h | 통합, 키오스크 시나리오 연결 |
| 10-13h | 버그 수정, 시연 시나리오 연습 |
| 13-14h | 발표 자료, 최종 `main` 병합 |
