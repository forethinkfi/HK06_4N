# 곁에(GYEOT-E) — 디자인 가이드 (DESIGN.md)

카카오 로그인 디자인 가이드의 색·형태 규정을 기준으로 삼고, 시니어 모바일 UX 원칙을 더해 정리한 곁에 UI 가이드입니다.

## 0. 문서 사용법

| 표시 | 의미 |
|---|---|
| **[카카오 규정]** | 카카오 로그인 디자인 가이드에 실제로 적힌 값. 임의로 바꾸지 않는다 |
| **[팀 제안]** | 카카오 문서에 없고, 시니어 UX 팁과 와이어프레임을 바탕으로 팀이 정한 값. 팀 합의로 조정 가능 |

**범위 주의**
- 참고한 카카오 문서는 **카카오 로그인 버튼** 가이드이며, 앱 전체 디자인 시스템이 아니다. 색상(노란색·검정)과 컨테이너 radius 12px 같은 값만 가져오고, 글자 크기·간격·화면 구성은 [팀 제안]으로 정의한다.
- 곁에는 **카카오 파생 서비스**이므로 카카오의 노란색(`#FEE500`)과 검정을 곁에의 기본 색으로 사용한다.
- 출처
  - 카카오 로그인 디자인 가이드: https://developers.kakao.com/docs/ko/kakaologin/design-guide
  - 시니어 세대를 위한 모바일 UX 디자인 Tips (DIGITAL iNSIGHT, 2020.11.09): https://ditoday.com/ux-tips/

## 1. 디자인 원칙

페르소나는 79세 김정성 씨다. 길은 잘 알지만 앱 조작이 어렵다. "노인 전용" 느낌이 나지 않으면서 취약한 부분을 일부 고려한다.

1. **한 화면에 한 가지**: 한 화면에 질문 하나, 행동 하나만 둔다. (One thing per page)
2. **말이 기본, 버튼은 보조**: 음성 대화가 기본 입력이고 큰 버튼은 "말이 안 통하나요?" 안의 보조 수단이다.
3. **익숙한 모양**: 새로운 패턴보다 이미 아는 레이아웃과 색을 쓴다.
4. **색에 기대지 않기**: 의미는 색이 아니라 글자와 굵기로 전한다.
5. **어린아이 대하듯 하지 않기**: 과한 칭찬, 지나치게 귀여운 표현은 피한다.

## 2. 색상

### 2-1. 카카오 규정 색 **[카카오 규정]**

| 용도 | 색 | 값 |
|---|---|---|
| 컨테이너(버튼 배경) | 카카오 옐로우 | `#FEE500` |
| 심볼 | 검정 | `#000000` |
| 레이블(글자) | 검정 85% | `rgba(0, 0, 0, 0.85)` (`#000000` 불투명도 85%) |

- 규정에 없는 색을 카카오 로그인 버튼에 적용하지 않는다.
- 버튼 색을 지정하지 않아 타사 로그인 버튼이 더 눈에 띄게 해서는 안 된다.

### 2-2. 곁에 UI 색 팔레트 **[팀 제안]**

| 토큰 | 값 | 용도 |
|---|---|---|
| `color-primary` | `#FEE500` | 주요 버튼 배경, 강조 |
| `color-on-primary` | `#000000` | 주요 버튼 위 글자·아이콘 |
| `color-text` | `rgba(0,0,0,0.85)` | 기본 글자 |
| `color-text-sub` | `#595959` | 보조 설명 |
| `color-surface` | `#FFFFFF` | 화면 배경 |
| `color-surface-sub` | `#F5F5F5` | 보조 버튼·카드 배경 |
| `color-border` | `#BDBDBD` | 구분선·테두리 |
| `color-danger` | `#C62828` | 경고(항상 글자와 함께 표시) |

### 2-3. 대비 규칙 **[팀 제안, 출처: 시니어 UX Tips]**

- 일반 글자는 배경과의 대비가 **4.5:1 이상**, 큰 글자는 **3:1 이상**이어야 한다.
- 기본 조합의 대비(계산값)
  - `#FEE500` 위 검정 글자 → 약 16:1 (사용 가능)
  - 흰 배경 위 `#595959` → 약 7:1 (사용 가능)
  - `#FEE500` 위 **흰 글자 → 약 1.3:1 (금지)**
  - 흰 배경 위 `#888888` 이하 회색 글자 → 4.5:1 미달 (금지)
- 중요한 아이콘에 파란색 계열을 쓰지 않는다.
- 빨강/초록 조합만으로 상태를 구분하지 않는다. 글자와 굵기를 함께 쓴다.
- 이미지나 카메라 화면 위에 글자를 겹치지 않는다. 필요하면 불투명한 배경 띠를 깐다.
- 화면을 그레이스케일로 바꿔도 모든 정보가 읽히는지 확인한다.
- 파스텔톤은 쓰지 않는다.
- 검사 도구: WebAIM Contrast Checker

## 3. 타이포그래피 **[팀 제안, 출처: 시니어 UX Tips]**

- 서체는 OS 기본 시스템 서체를 쓴다. (카카오 로그인 버튼 규정과 동일) 글꼴은 1~2개로 통일한다.
- **메인 글자 크기는 16px**이다. 이보다 작은 글자는 쓰지 않고, 핵심 문구와 제목은 16px보다 크게 쓴다.
- 카카오 가이드는 로그인 버튼 글자 크기를 Pt(Sp/Dp) 단위로 안내한다(정확한 수치는 원문 확인 필요). 카카오 로그인 버튼은 그 규정을 따르고, 그 외 UI의 크기 단위는 px로 통일한다.

| 토큰 | 크기 | 굵기 | 용도 |
|---|---|---|---|
| `text-body` | **16px** | Regular | **메인 글자: 일반 설명, 기본 문장** |
| `text-caption` | 16px | Regular | 보조 설명 (색은 `color-text-sub`, 16px보다 작게 쓰지 않음) |
| `text-button` | 18px | Bold | 버튼 글자 |
| `text-title` | 20px | Bold | 화면 제목 |
| `text-avatar` | 24px | Bold | 아바타가 하는 말(화면의 핵심 문장) |

- 한 문장에 한 동작만 쓴다. 문장이 길어져도 괜찮지만 동작은 하나만 담는다.
- 사용자가 글자 크기를 바꿀 수 있는 옵션을 제공하면 좋다. (시간이 되면)

## 4. 버튼과 터치 영역

### 4-1. 카카오 로그인 버튼 **[카카오 규정]**

- 구성: 말풍선 모양 **심볼** + 안내 **레이블** + 이를 감싸는 **컨테이너**
- 컨테이너 radius: **12px**
- 레이블: 완성형 "카카오 로그인", 축약형 "로그인"
- 심볼 규칙
  - 심볼의 형태·비율·색을 바꾸지 않는다.
  - 카카오 CI를 심볼로 대신 쓰지 않고, 기능 아이콘을 심볼로 쓰지 않는다.
  - 심볼 없이 버튼을 구성하지 않는다.
- 가로를 늘릴 때: 심볼과 레이블 영역은 그대로 두고 컨테이너를 좌우 동일하게 늘린다. 심볼은 왼쪽 정렬하거나 레이블과 함께 가운데 정렬한다. 레이블의 자간과 크기는 바꾸지 않는다.
- 전체를 키울 때: 심볼과 레이블 비율을 유지해 함께 키운다. 레이블 높이는 컨테이너 높이의 1/3을 넘지 않는다.
- 작게 써야 할 때: 비율을 억지로 줄이지 말고 축약형 "로그인"을 쓴다.
- 곁에 앱에 로그인 화면이 필요하다면 위 규정을 그대로 따른다. (현재 와이어프레임에는 로그인 화면이 없음)

### 4-2. 곁에 버튼 **[팀 제안]**

곁에는 카카오 로그인 버튼이 아니므로 카카오 심볼은 쓰지 않는다. 대신 컨테이너 형태(radius 12px)와 색 대비 규칙만 맞춘다.

| 종류 | 배경 | 글자 | 용도 |
|---|---|---|---|
| 주요(Primary) | `#FEE500` | `#000000` | 한 화면의 가장 중요한 선택 |
| 보조(Secondary) | `#F5F5F5` | `rgba(0,0,0,0.85)` | 그 외 선택, 닫기 |
| 비활성 | `#EEEEEE` | `#595959` | 아직 누를 수 없음 (글자로 이유 표시) |

- radius는 12px로 통일한다.
- **터치 영역**: 시니어 UX Tips는 대각선 최소 9.6mm(iPad는 44×44px)를 권장한다. 곁에는 여유 있게 **높이 56px 이상, 주요 버튼은 72px 이상**으로 한다.
- 버튼 사이 간격은 **16px 이상**으로 둬서 손떨림으로 잘못 누르는 일을 줄인다.
- 한 화면에 **주요 버튼은 하나**만 둔다.
- 작은 아이콘 단독 버튼을 쓰지 않는다. 아이콘에는 항상 글자를 붙인다.
- 과한 반복 탭을 요구하지 않는다. 글자 입력 대신 음성과 선택 버튼을 쓴다.

## 5. 레이아웃 **[팀 제안]**

- 기준 화면: 390 × 844 (와이어프레임 기준), 좌우 여백 24px
- **중요한 요소는 화면 중앙에** 둔다. 아바타와 핵심 문장을 가장 크게 중앙 영역에 배치한다.
- 영상통화 느낌을 위해 아바타를 화면에서 가장 크게 보여주고, 보조 버튼은 아래쪽 "말이 안 통하나요?" 창에 둔다.
- 한 화면에 두 가지 이상 정보가 들어가면 구역을 분명히 나눈다.
- 지도 화면은 출발지와 목적지만 강조하고 그 외 정보는 줄인다.

### 구성 요소

| 요소 | 규칙 |
|---|---|
| 아바타 말 영역 | 가장 큰 글자(`text-avatar`), 화면 상단 또는 아바타 근처 |
| 듣기 표시 | `● 듣고 있어요` 항상 표시. 색만이 아니라 글자로 상태 전달 |
| 보조 버튼 창 | "말이 안 통하나요?"를 누르거나 위로 밀면 열림. "닫기"로 아바타 화면 복귀 |
| AI 표시 | "가족 모습으로 만든 AI 도우미"임을 첫 화면에서 알리고 이후에도 구분할 수 있게 유지 |
| 카메라 안내 | 반드시 멈춘 상태에서 사용. 화살표는 크고 단순하게. 글자는 띠 위에 표시 |

## 6. 인터랙션과 피드백 **[팀 제안]**

- 사용자가 한 행동에는 즉시 반응한다. (마이크로 인터랙션: 듣는 중 표시, 말하는 아바타 움직임)
- 단계가 끝날 때마다 분명하게 알린다. (예: "택시를 불렀어요", "잘 오셨어요!")
- 대기 시간은 넉넉히 준다. 응답이 없으면 재촉하지 말고 "천천히 하세요"로 기다린다.
- 못 알아들었을 때는 다시 말하기와 큰 선택 버튼을 함께 제시한다.
- 외부 앱(카카오 택시)으로 넘어가기 전에 무엇이 열리는지 미리 말해준다.

---

## 7. 문구 톤 **[팀 제안]**

- 손주가 실제로 할 법한 말투. 기계적인 표현을 쓰지 않는다. (자세한 대본은 [VOICE_SCRIPT.md](./VOICE_SCRIPT.md))
- 한 문장에 하나의 행동만 안내한다.
- 노인 전용이라는 느낌이 나는 표현("어르신용" 등)을 화면에 쓰지 않는다.

---

## 8. 체크리스트

- [ ] 메인 글자는 16px이고, 16px 미만 글자가 없으며 핵심 문장은 24px인가
- [ ] 글자 대비가 4.5:1(큰 글자 3:1) 이상인가
- [ ] 그레이스케일로 봐도 읽히는가
- [ ] 한 화면에 질문과 행동이 하나인가
- [ ] 버튼 높이 56px 이상, 간격 16px 이상인가
- [ ] 주요 버튼이 화면당 하나인가
- [ ] 이미지·카메라 화면 위에 글자가 겹치지 않는가
- [ ] 카카오 로그인 버튼을 쓴다면 색(`#FEE500` / `#000000` / 검정 85%)과 radius 12px, 심볼 규칙을 지켰는가
- [ ] AI 도우미임을 알 수 있는가
