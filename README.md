# 🤝 곁에 (HK06_4N)

> 어르신이 앱을 켜고 "병원 가게 택시 잡아줘"라고 말하면, 영상통화처럼 보이는 **가족 아바타**가 손주 목소리로 짧은 문장을 하나씩 말하며 택시 부르기부터 도착까지 돕는 AI 도우미

해커톤 프로젝트입니다. **택시 부르기가 메인**이고 길찾기가 함께 들어갑니다. 이번 MVP는 **실제 택시·결제 연동이 없는 예시안**입니다.

- 시연 페이지: <https://gyeotae-hk06-4n.netlify.app/>
- 자세한 기획: [`docs/PRD.md`](docs/PRD.md) · 유저저니: [`docs/USER_JOURNEY.md`](docs/USER_JOURNEY.md) · 디자인: [`docs/DESIGN.md`](docs/DESIGN.md) · 음성 대본: [`docs/VOICE_SCRIPT.md`](docs/VOICE_SCRIPT.md)

## 왜 만들었나

- 요즘 택시는 앱 호출·예약이 중심이라, 길에서 손을 들어도 빈 택시를 잡기 어렵습니다. 앱을 못 쓰면 택시를 타기 어려워졌습니다.
- 어르신은 길은 알아도 택시 앱의 메뉴, 위치 설정, 호출 방법이 낯설고, 같은 이름의 다른 장소로 잘못 가기도 합니다.
- 가족은 전화로 "거기서 왼쪽으로 가"를 반복해야 하고, 직접 데려다줄 수 없는 경우가 많습니다.
- 어르신께 필요한 것은 기능 설명이 아니라 **믿는 사람이 옆에서 하나하나 말해 준다는 안심감**입니다. 아는 가족의 얼굴과 목소리가 말해 주면 새 앱이라는 거부감이 줄어, 영상통화하듯 편하게 시작할 수 있습니다.

## 시연 한 줄

평일 오전 10시, 불광동 자택에서 김정성 할아버지(합성 페르소나)가 "병원 가게 택시 잡아줘"라고 말하면

1. 등록된 **행복대학병원**을 고르고 "맞아요?"로 확인합니다.
2. 집 안에서 **타는 곳**(○○아파트 101동 앞, 지도·사진), **결제 방법**, **나갈 준비**, **예상 요금**을 차례로 확인하고 ⭕일 때만 택시를 부릅니다(모의 호출).
3. 배차되면 **차 사진·차종·번호**와 **택시 위치 지도**를 보여주고, 도착 예정 시간을 알려 줍니다.
4. "택시가 보이세요?", "차 번호가 맞나요?"를 확인한 뒤 탑승하고, 도착 전 **내릴 준비** 안내와 도착 후 **칭찬**까지 듣습니다.

병원 이름, 아파트, 요금, 시간은 모두 가상 예시입니다.

## 핵심 기능

### 어르신 — MVP(필수)

| 기능 | 내용 |
| --- | --- |
| 말하는 아바타 화면 | 앱을 열면 가족 아바타, "AI 도우미" 표시, 큰 말하기 버튼이 보이고 바로 듣기 시작. 첫 인사에서 AI임을 알림 |
| 음성으로 주고받기 | 네·아니요 질문은 화면에 큰 [⭕] [❌] 버튼만. "네/응/맞아/그래"는 ⭕, "아니요/아니/아니야"는 ❌. 도우미가 말하는 동안은 듣지 않음 |
| 병원 선택과 확인 | 등록한 대학병원·동네 내과와 [다른 병원]. 같은 이름이 여러 곳이면 가까운 곳부터 지역과 함께 "맞아요?"로 확인 |
| 택시 부르기 (메인) | 타는 곳 → 결제 방법 → 나갈 준비 → 최종 확인(출발지·도착지·예상 요금·결제) → 모의 호출. 수정·중단·취소 가능 |
| 차량 정보와 택시 위치 지도 | 배차 팝업(차 사진·차종·번호) → 화면 아래 카드. 지도에서 택시 위치와 도착 예정 시간 표시 |
| 탑승 확인 · 내릴 준비 · 도착 칭찬 | 번호가 다르면 "이 차는 타지 마세요." 도착 전 소지품·하차 안내, 도착 후 칭찬과 격려 |
| 짧은 문장 길 안내 | 한 문장에 한 동작, 장소 이름 중심("약국에서 왼쪽으로 가세요"). "알겠어"라고 하면 다음 단계 |
| 실패 시 선택 버튼 | 음성 인식 실패, 마이크 불가, 소음, 무응답일 때 지금 질문에 맞는 버튼과 "다시 알려줘"가 나타남 |

### 시간이 되면 (P1)

카메라로 방향 보기(큰 화살표), 지도 화면 자동 전환, 지금 상태 카드와 자동 반복, 뒤로가기, AI 말뜻 이해, 가족 설정 화면(동의·집 주소·병원·카드·어르신 말 등록), 사진을 아바타로 변환

### 이후 단계

실제 GPS·지도 API, 실제 카카오 택시 호출·결제 연동, 자유롭게 대화하는 AI 도우미, 가족 목소리 실시간 생성, 아바타 입 움직임, 사투리·발음 학습, 전철·버스·시외버스 예약, 키오스크 안내, 가족 연동

## 시연과 실제 서비스의 차이

발표에서 반드시 밝히는 내용입니다.

| 항목 | 시연 (예시안) | 실제 서비스 |
| --- | --- | --- |
| 택시 호출·결제 | 앱 안의 모의 호출. 요금·배차·택시 이동·도착은 정해 둔 화면과 시간 | 카카오 택시 호출·결제 연동 (카카오 파생 서비스 가정, 연동 가능 여부 미확인) |
| 위치·지도 | 가상 위치와 미리 정한 경로, 네이버 지도 이미지·예시 지도 | 폰의 GPS·나침반과 지도 API |
| 목소리 | 미리 녹음·생성해 둔 짧은 안내 문장 | 가족 목소리를 학습해 어떤 문장이든 실시간 생성 |
| 대화 | 정해진 짧은 말에 반응 (AI 말뜻 이해가 되면 다양한 말도 이해) | 말을 이해하고 상황에 맞게 대답하는 대화형 AI |
| 아바타 입 움직임 | 시연에서 제외, 발표용 영상으로만 보여줌 | 목소리에 맞춰 입 모양과 표정이 움직임 |
| 사투리 | 가족이 등록한 어르신만의 말로 알아들음 (AI 학습 아님) | 녹음으로 사투리·발음 학습 검토 |

## 시작하기

```bash
git clone https://github.com/forethinkfi/HK06_4N.git
cd HK06_4N/frontend
python -m pip install -U google-genai   # Gemini 음성 기능을 쓸 때만
python gyeotae-maps-local.py            # Windows는 py gyeotae-maps-local.py
```

브라우저에서 <http://localhost:8765>를 엽니다. 서버 파일과 `gyeotae-s25-ultra.html`은 같은 폴더에 있어야 합니다.

API 키는 **환경 변수**로 넣거나 앱의 **설정 입력칸**에 넣습니다. 코드에는 절대 넣지 않습니다.

| 환경 변수 | 용도 |
| --- | --- |
| `GYEOTAE_MAPS_KEY_ID`, `GYEOTAE_MAPS_KEY` | 네이버 지도 API (NCP Maps) |
| `GEMINI_API_KEY` | Gemini 음성·대화 |
| `ORS_API_KEY` | openrouteservice 도보 경로 |
| `GEMINI_DIALOGUE_MODEL` | 대화 모델 이름 (선택) |

- 실제 가족 사진과 목소리, 실제 주소는 **저장소에 올리지 않습니다.** 테스트는 샘플 파일과 가짜 주소로 합니다.

## 안전과 개인정보 원칙

- 화면에 **"AI 도우미"를 항상 표시**하고, 첫 인사에서 손주의 모습과 목소리로 만든 AI임을 알립니다.
- 시연은 **미리 만든 고정 문장**만 사용합니다. 가족 목소리 실시간 복제는 보이스피싱 위험을 설계한 뒤 도입합니다.
- 사진·목소리 주인과 어르신 본인의 **동의**를 먼저 받고, 동의하지 않은 기능은 켜지 않습니다.
- 택시는 최종 질문에 ⭕일 때만 부르고, 대답이 없거나 알아듣지 못하면 부르지 않습니다.
