# 🤝 곁에 (HK06_4N)

> 어르신이 말로 "나 병원 갈 건데 택시 잡아줘"라고 하면, 영상통화처럼 보이는 **가족 아바타**가 짧은 말로 한 단계씩 안내하며 택시를 불러 주는 AI 도우미

14시간 해커톤 프로젝트입니다. 자세한 기획은 [`docs/PRD.md`](docs/PRD.md)를 보세요.

## 왜 만들었나

- 요즘 택시는 앱 호출이 중심이라, 앱을 못 쓰면 택시를 타기 어렵습니다.
- 지도 앱은 어르신께 낯설고, 가족은 전화로 "거기서 왼쪽으로 가"를 반복해야 합니다.
- 어르신께 필요한 것은 기능 설명이 아니라 **믿는 사람이 옆에서 말해 준다는 안심감**입니다. 낯선 앱 대신 아는 가족의 얼굴로 영상통화하듯 편하게 시작하게 만듭니다.

## 시연 한 줄

할아버지가 앱을 켜고 "병원 가고 싶어"라고 말하면 → 같은 이름 병원 중 가까운 곳을 확인하고 → 가까우면 걸어가는 길을, 멀면 택시를 부르는 것을 아바타가 돕습니다. 택시는 출발지·도착지·요금을 큰 글씨로 확인한 뒤 곁에가 직접 부르고, "여기서 기다리세요"까지 안내합니다.

## 핵심 기능

**어르신 (MVP 필수)**
1. **말하는 아바타 화면**: 앱을 열면 가족 아바타가 나오고 바로 듣기 시작. 화면에 항상 "AI 도우미" 표시
2. **음성으로 주고받기**: "응/아니", "알겠어", "다시", "잠깐" 같은 짧은 말로 대화, 눌러서 답하는 버튼도 함께 제공
3. **같은 이름 장소 확인**: 가까운 곳부터 지역과 함께 "맞아요?"라고 꼭 확인, 확인 없이는 넘어가지 않음
4. **택시 부르기 (메인)**: 타는 곳 확인 → 출발지·도착지·요금 확인 → 카카오 택시 호출 → 도착 알림과 기다리기 안내
5. **짧은 문장 길 안내**: 한 문장에 한 동작씩, 미리 정한 경로를 가상 위치 기준으로 안내
6. **실패 대비**: 음성 인식이 틀리면 "다시 알려줘"와 장소 선택 버튼이 있는 별도 화면

**시간이 되면 (P1)**: 카메라로 방향 큰 화살표 보기, 지도 보기 목업, AI 말뜻 이해, 가족 설정(자주 가는 곳, 사진 → 아바타 변환), 어르신 말 등록(사투리나 부르는 이름)

**이후 단계**: 실제 GPS·지도 API, 자유 대화 AI, 가족 목소리 실시간 생성, 입 움직임과 목소리 녹음, 안드로이드 화면 위 도우미, 전철·버스·시외버스 예약 확장

## 시연과 실제 서비스의 차이

발표에서 분명히 밝히는 내용입니다.

| 항목 | 시연 | 실제 서비스 |
| --- | --- | --- |
| 목소리 | 미리 녹음한 음성 파일 | 가족 목소리를 학습해 실시간 생성 |
| 위치 | 가상 위치, 미리 정한 경로 | 폰의 GPS·나침반·지도 API |
| 택시 호출 | 앱 안의 모의 호출, 요금은 예시 금액, 도착 알림은 시간으로 대체 | 카카오모빌리티 제휴·API 연동 |
| 대화 | 정해진 짧은 말에 반응 | 말을 이해하고 대답하는 대화형 AI |
| 아바타 입 움직임 | 시연에서 제외, 발표용 영상으로 보여줌 | 목소리에 맞춰 움직임 |

## 폴더 구조

| 폴더 | 내용 |
| --- | --- |
| `frontend/` | 웹앱 전체 (아바타 화면, 음성 인식, 길안내, 택시 흐름, 가족 설정, AI API 호출) |
| `assets/` | 아바타 이미지, 안내 음성 파일, 지도 이미지 |

## 기술 스택

서버 없는 **웹앱**이고 GitHub Pages로 배포합니다. (폰에서 마이크·카메라를 쓰려면 https가 필요합니다.)

| 기능 | 기술 |
| --- | --- |
| 음성 인식 | Web Speech API (안드로이드 크롬 권장) |
| 카메라 | getUserMedia |
| 저장 | localStorage, IndexedDB (본인 폰에만 저장) |
| 안내 목소리 | 미리 녹음한 음성 파일 |
| 아바타 변환·말뜻 이해 | Gemini 또는 OpenAI API (미정, Claude는 이미지 생성 불가) |
| 택시 호출 | 시연은 앱 안의 모의 호출 |

## 시작하기

```bash
git clone https://github.com/forethinkfi/HK06_4N.git
cd HK06_4N
git checkout develop
```

- AI API 키는 **코드에 넣지 않고** 앱의 입력칸에 직접 입력합니다. (본인 폰에만 저장)
- 실제 가족 사진과 목소리는 **저장소에 올리지 않습니다.** 테스트는 샘플 파일로 합니다.
