# 🐾 HK06_4N — 손주 펫봇

> 손주의 사진으로 만든 펫봇이 내 폰 화면을 떠다니며, 키오스크 같은 어려운 일을 만났을 때 AI 챗봇으로 도와주는 어르신 전용 도우미

14시간 해커톤 프로젝트입니다.

## 핵심 기능

1. **손주 펫봇 생성** — 손주 사진으로 펫봇 외형(캐릭터) 만들기
2. **화면 위 플로팅** — 핸드폰 화면 위를 떠다니는 펫봇 (탭하면 대화 시작)
3. **AI 도움 챗봇** — 키오스크 주문, 앱 사용법 등을 쉬운 말로 단계별 안내 (음성/큰 글씨 지원)

## 폴더 구조

| 폴더 | 내용 |
| --- | --- |
| `frontend/` | 앱/화면 (펫봇 UI, 플로팅, 채팅) |
| `backend/` | 서버, AI 챗봇 API, 이미지 처리 |
| `assets/` | 이미지, 캐릭터 리소스 |
| `docs/` | 기획, API 명세, 발표 자료 |

## 브랜치 전략 (해커톤용 간소화)

| 브랜치 | 용도 |
| --- | --- |
| `main` | 시연/제출용 안정 버전 |
| `develop` | 통합 브랜치 (여기로 PR) |
| `feature/*` | 기능 개발 (`develop`에서 분기) |
| `fix/*` | 버그 수정 |

규칙
- `main`, `develop`에 직접 푸시하지 않고 PR로 병합
- PR은 작게, 자주 (14시간이므로 오래 들고 있지 않기)
- 충돌 방지를 위해 담당 폴더/파일을 나눠서 작업
- 커밋: `type: 내용` (`feat`, `fix`, `docs`, `style`, `refactor`, `chore`)
