# 🤝 곁에 (HK06_4N)

> 어르신이 말로 "나 병원 갈 건데 어떻게 가?"라고 하면, 영상통화처럼 보이는 **가족 아바타**가 **가족 목소리**로 길을 한 단계씩 알려주는 AI 도우미

14시간 해커톤 프로젝트입니다. 자세한 기획은 [`docs/PRD.md`](docs/PRD.md), 일정은 [`docs/PLAN.md`](docs/PLAN.md)를 보세요.

## 왜 만들었나

- 요즘 택시는 앱 호출이 중심이라, 앱을 못 쓰면 타기 어렵습니다.
- 지도 앱은 어르신께 낯설고, 가족은 전화로 "거기서 왼쪽으로 가"를 반복해야 합니다.
- 어르신이 따르는 건 **아는 사람의 얼굴과 목소리**입니다. 낯선 앱 대신 영상통화하듯 편하게 시작하게 만듭니다.

## 핵심 기능 (MVP)

**어르신**
1. **말하는 아바타 화면**: 앱을 열면 가족 아바타만 보이고 바로 듣기 시작 (입 움직임 포함)
2. **음성으로 목적지 요청**: "병원 가고 싶어" → 같은 이름 장소가 여럿이면 가까운 곳부터 "맞아요?" 확인
3. **택시 부르기 (메인)**: 타는 곳 확인 → 카카오 택시 연결 → "여기서 기다리세요"
4. **짧은 문장 길 안내**: 한 문장에 한 동작씩, 가족 목소리 파일로 재생 (가상 위치 기준)
5. **실패 대비**: "다시 알려줘" 버튼, 선택 버튼

**가족**
- 사진 → 아바타 변환, 목소리 녹음, 자주 가는 곳 등록 (시간이 되면)

**시간이 되면:** 카메라로 방향 화살표 보기, 지도 보기 목업, AI 말뜻 이해

**이후 단계:** 실제 GPS·지도 API, 자유 대화 AI, 실시간 목소리 복제, 안드로이드 화면 위 도우미

## 폴더 구조

| 폴더 | 내용 |
| --- | --- |
| `frontend/` | 웹앱 전체 (아바타 화면, 음성 인식, 길안내, 가족 설정, AI API 호출) |
| `assets/` | 아바타 이미지, 안내 목소리 파일, 지도 이미지 |

## 기술 스택

서버 없는 **웹앱**, GitHub Pages로 배포합니다 (폰에서 마이크·카메라를 쓰려면 https 필요).

| 기능 | 기술 |
| --- | --- |
| 음성 인식 | Web Speech API (안드로이드 크롬 권장) |
| 아바타 입 움직임 | Web Audio |
| 카메라 | getUserMedia |
| 가족 녹음 | MediaRecorder |
| 저장 | localStorage, IndexedDB (본인 폰에만 저장) |
| 안내 목소리 | 일레븐랩스로 미리 만든 음성 파일 |
| 아바타 변환·말뜻 이해 | Gemini 또는 OpenAI API (미정, Claude는 이미지 생성 불가) |

## 시작하기

```bash
git clone https://github.com/forethinkfi/HK06_4N.git
cd HK06_4N
git checkout develop
```

- AI API 키는 **코드에 넣지 않고** 앱의 입력칸에 직접 입력합니다 (본인 폰에만 저장).
- 실제 가족 사진과 목소리는 **저장소에 올리지 않습니다.** 테스트는 샘플 파일로 합니다.
